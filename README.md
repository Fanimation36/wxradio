# NWR Streams — WXM49

Static GitHub Pages station page for the WXM49 receiver stream.

Stream: https://wxm49.duckdns.org/wxm49
Status: https://wxm49.duckdns.org/status-json.xsl

The coverage graphic is an illustrative reception guide, not a propagation prediction. County coverage text is based on NWS Paducah's NOAA Weather Radio coverage appendix. The official NOAA Weather Radio All Hazards logo is intentionally not bundled; NWS requires written authorization for use of that registered mark.
