# NWR Streams — WXM49
Upload these files to the root of your GitHub Pages `wxradio` repository. The page uses `https://wxm49.duckdns.org/wxm49` for audio and `https://wxm49.duckdns.org/status-json.xsl` for status/listener data.

The Illinois map uses `assets/illinois.png`, based on the supplied accurate Illinois silhouette. Coverage rings are illustrative, not a propagation prediction.


Volume UP/DOWN hotspots on the WR-120 change stream volume in 10% steps and play assets/button_press.wav.
